このツールで何ができる?

■ 用途

本ツールは、7020ライン製品(照明器具)の在庫状況を、ペットネーム(=製品の愛称)別に見える化するためのものです。

以下の2つのExcelファイルを食わせるだけで、6シート構成の集計Excelが数十秒で出来上がります。

入力出力
■ 型番とペットネーム対比表.xlsx
■ 7020製品在庫YYMMDDHHMM.xlsx 		■ 7020製品在庫集計結果_YYYYMMDD.xlsx(6シート)

■ 具体的に出力されるもの

  • ペットネーム別の実残・販売・引当の集計表(pivot)
  • 在庫明細に、ペットネームと種別と販売区分、岩崎/伊東の判定を追記したもの
  • マスターに登録されていない型番のリスト(NG)
  • マスターに重複登録されている型番のリスト

ステップ1: ツールを起動する

  1. HTMLファイルの場所を開く

    エクスプローラーで 7020在庫集計.html が保存されている場所を開きます。

  2. ダブルクリックで起動

    ファイルをダブルクリックすると、既定のブラウザで自動的に画面が開きます。

  3. 画面表示を確認

    以下のような画面が表示されれば起動成功です。

file:///C:/Users/.../Desktop/7020在庫集計.html
[画面キャプチャ] 起動直後の画面(KPIは全て0件、2つのドロップ領域が待機状態)
■ 注意: ダブルクリックしてもInternet Explorerが起動してしまう場合は、 HTMLファイルを右クリック → 「プログラムから開く」→ Microsoft Edge または Google Chromeを選択してください。
2
ステップ2: Excelファイルを読み込む

  1. 型番マスターをドロップ(ドロップ領域①)

    画面左側の点線枠内に 「型番とペットネーム対比表.xlsx」をドラッグ&ドロップします。

    またはドロップ領域をクリックしてファイル選択ダイアログからも選べます。

  2. 読み込み成功のサインを確認

    読み込みが完了すると、以下のように表示が変わります:

    • ドロップ領域の背景色が緑に変わる
    • ファイル名と行数が表示される
    • KPIカード「全型番マスター件数」「見込型番数」の数字が更新される

  3. 在庫Excelをドロップ(ドロップ領域②)

    画面右側の点線枠内に 「7020製品在庫YYMMDDHHMM.xlsx」をドロップ。

    KPIカード「在庫件数」の数字が更新されます。

file:///C:/Users/.../7020在庫集計.html
[画面キャプチャ] 両ファイル読込後の状態(ドロップ領域が緑に変化、下部のログに結果表示)
■ 読み込まれるシート:
型番マスター → シート「全型番とペットネーム」
在庫Excel → シート「7020ZAI」
※シート名が異なるとエラーメッセージが出ます。
3
ステップ3: 集計を実行する

  1. 集計実行 ボタンをクリック

    画面上部にある青色のボタンをクリックします。

  2. 進捗ログを確認

    画面下部の黒いログエリアに、処理の進捗が順次表示されます。

    [23:30] 集計開始...
    [23:30] マスター照合中...
    [23:30] 岩崎/伊東判定中...
    [23:30] NGリスト検出中...
    [23:30] 重複型番検出中...
    [23:30] ■ 集計完了: zaiko=1442, NG=0, 重複=1

  3. KPIが更新される

    「マッチ済」「NG件数」「重複件数」のKPIカードに実際の値が反映されます。

■ 所要時間の目安: 在庫1,000〜2,000行で10〜30秒程度。 大量データの場合、ブラウザのタブを閉じずにそのままお待ちください。
4
ステップ4: 画面上で結果を確認する

■ 確認できる4つのビュー

① KPIカード(画面上部)

一目で6つの指標を把握できます。

  • 在庫件数
  • 全型番マスター件数
  • 見込型番数(全型番から抽出)
  • マッチ済件数
  • NG件数(未登録型番)
  • 重複件数(マスター内重複)

② 在庫pivot(画面中央)

ペットネーム別に実残・販売・引当を集計した表。

  • ペットネーム列(行ラベル)
  • 合計 / 実残
  • 合計 / 販売
  • 合計 / 引当
  • 最下行に総計

③ NGリスト(タブで切替)

マスターに登録されていない型番の一覧。
0件が理想。1件以上あればマスターの追加検討が必要です。

④ マスター重複(タブで切替)

マスターで同じ型番が複数回登場する行のリスト。
重複があってもエラーにはなりませんが、意図しない重複はマスター修正を推奨。

[画面キャプチャ] 集計後のpivot表示例(ペットネーム別の実残・販売・引当を一覧化)

ステップ5: フィルタで絞り込む(任意)

画面中央にある4つのドロップダウンで、pivot表の集計対象を絞り込めます。

フィルタ選択肢用途例
岩崎 / 伊東(全て) / EYE / ITO / 例外岩崎電気分だけ見たい時
種別(全て) / LED灯具 / HID灯具 / ランプ / NON ...LED品だけに絞って集計
販売区分(全て) / 受注 / 見込見込分だけ集計したい時
在庫事業所(全て) / 100 / 200 / ...特定事業所の在庫だけ見る時
■ フィルタ適用のタイミング: ドロップダウンを変更すると、即座にpivot表が再集計されます。
■ Excel出力への反映: この状態で「結果Excelダウンロード」すると、フィルタ適用後の値がpivotシートに記録されます(明細シートは全件)。
6
ステップ6: 結果Excelをダウンロードする

    緑色のボタンをクリックすると、ブラウザの標準ダウンロードが始まります。

  2. ファイル名の確認

    ダウンロードフォルダに 7020製品在庫集計結果_YYYYMMDD.xlsx という名前で保存されます。
    ※YYYYMMDDは当日の日付。例: 7020製品在庫集計結果_20261015.xlsx

  3. Excelで開いて中身を確認

    以下の6シートが順番に並んでいます。

データ管理

■ 自動保存(localStorage)

集計を実行すると、データはブラウザ内部に自動保存されます。 次回HTMLを開いても、前回の集計結果がそのまま表示されます。

■ 注意: データはブラウザ単位で保存されます。 EdgeとChromeは別々の保存領域なので、同じPCでも別物として扱われます。

■ 「保存データを消去」ボタン

保存データ消去 をクリックすると、確認ダイアログが出た後、全データが削除されます。

用途: 期をまたいで新しいデータを入れる時、テスト用データを消したい時 等

■ 「DBをバックアップ」ボタン

DBをバックアップ をクリックすると、現在のDBを .sqlite ファイルとしてダウンロードできます。

用途: 月末のスナップショット保存、別PCへの引継ぎ、障害時のリカバリ用

トラブルシューティング

■ Internet Explorer で開いてしまった

HTMLファイルを右クリック → 「プログラムから開く」→ Microsoft Edge か Google Chrome を選択してください。 常に Edge/Chrome で開くには「常にこのアプリで開く」にチェックを入れておくと便利です。

■ 「シートが見つかりません」エラーが出た

以下を確認してください。

  • マスターExcel: シート名が 全型番とペットネーム になっているか
  • 在庫Excel: シート名が 7020ZAI になっているか

Excelでシート名の末尾にスペースが入っているケースもあります。シート名のタブをダブルクリックして確認・修正してください。

■ ダウンロードした結果Excelでペットネームが空欄

Excelを開いた直後、保護されたビューの解除が必要な場合があります。
上部に黄色いバナーが出ていたら「編集を有効にする」をクリックしてください。

それでも空欄のままなら、キーボードの F9(全再計算)を押してください。

■ 動作が重い・集計が終わらない

在庫データが10,000行を超えると、集計に時間がかかります(最大1〜2分程度)。
ブラウザのタブを閉じずに、そのままお待ちください。
フリーズしているように見えても、画面下部のログが更新されていれば正常に動作しています。

■ ブラウザを再起動したらデータが消えた

以下のいずれかが原因と考えられます。

  • ブラウザの「閲覧履歴データを削除」でCookie/サイトデータを消去した
  • 別のブラウザ(例: Chrome → Edge)で開いた
  • プライベート/シークレットウィンドウで開いていた

対策: 大切なデータは「DBをバックアップ」ボタンで .sqlite ファイルに保存しておくと安全です。

■ NG件数が異常に多い

読み込んだマスターの範囲が狭すぎる、または在庫Excelの型番の表記ゆれが原因の可能性があります。

  • マスターExcelが最新版かどうか確認
  • 在庫Excelの「製品名」列に全角/半角の違いや、末尾の余分なスペースがないか確認

よくある質問
質問回答
通信は本当に発生しない? はい。全ての処理はブラウザ内で完結します。社内ネットワーク接続がなくても動きます。
複数PCで同じデータを共有したい DBバックアップ(.sqlite)をファイル共有ドライブに置き、各PCで「読込」する運用になります。
自動共有機能は今後の拡張予定です。
結果Excelを編集して保存してもよい? はい。VLOOKUP式が入っているので、Excel上でマスターを編集すれば7020ZAIシートも自動更新されます。
マスターに同じ型番が複数ある場合、どれが採用される? マスターExcel上で上の行(=sort_order 小)が採用されます。
重複は「マスター重複」シートに出力されるので、意図しない重複は確認・整理してください。
販売区分が空欄の行はどう扱われる? 内部的に「受注」として扱います。画面のpivotフィルタ・結果Excelとも「受注」と表示されます。
岩崎/伊東判定が「例外」になるのは? 製造部門コードが空欄、または末尾が0/1以外の場合「例外」と判定されます。
ツールを配布したい 7020在庫集計.html 1ファイルをメールやファイル共有で配るだけでOKです。1.8MBあります。
バージョンアップはどうやる? 新しい 7020在庫集計.html を上書き保存するだけ。保存データ(localStorage)はそのまま引き継がれます。
