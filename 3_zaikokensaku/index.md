# 7020製品在庫集計ワークフロー(スタンドアロン版)使い方

## 概要

このHTMLファイル1つで、7020製品在庫の集計ワークフローがローカルPC上で完結します。
サーバー通信は一切行わず、データはブラウザ内部(localStorage)に保存されます。

## 動作環境

- **OS**: Windows 10 / 11
- **ブラウザ**: Microsoft Edge または Google Chrome(いずれも最新版推奨)
- **通信**: **不要**(オフライン動作)
- **インストール**: **不要**(HTMLファイルをダブルクリックするだけ)

## 起動方法

1. `7020在庫集計.html` を任意のフォルダに保存
   (例: デスクトップ、ドキュメントフォルダ、社内共有ドライブなど)
2. ファイルをダブルクリック → 既定のブラウザが起動して画面が表示されます

> **補足**: 既定のブラウザが Internet Explorer になっている場合、ファイルを右クリック →
> 「プログラムから開く」→ Microsoft Edge または Google Chrome を選んでください。

## 使い方

### 基本フロー

1. **ファイル①** をドロップまたはクリックして選択:
   - `型番とペットネーム対比表.xlsx`
   - シート「全型番とペットネーム」を読み込み、そのうち販売区分='見込'の行を自動で見込マスターとして抽出します
2. **ファイル②** をドロップまたはクリックして選択:
   - `7020製品在庫YYMMDDHHMM.xlsx`
   - シート「7020ZAI」を読み込みます
3. **「集計実行」** ボタンをクリック
   - マスターとの照合、NG(未登録型番)検出、重複型番検出が自動で走ります
4. **「結果Excelをダウンロード」** ボタンをクリック
   - `7020製品在庫集計結果_YYYYMMDD.xlsx` (6シート構成)がダウンロードフォルダに保存されます

### 画面上の確認機能

- **KPIカード** (6項目): 在庫件数 / 全型番マスター件数 / 見込型番数 / マッチ済 / NG件数 / 重複件数
- **在庫pivot**: ペットネーム別に実残・販売・引当を集計。4種のフィルタ(岩崎伊東/種別/販売区分/在庫事業所)で絞り込み可能
- **NGリスト**: 型番マスターに未登録の在庫型番一覧
- **マスター重複型番リスト**: 全型番マスターで同じ型番が複数回登場する行

### 結果Excelの6シート構成

| # | シート名 | 内容 |
|---|---|---|
| 1 | 在庫pivot | ペットネーム別集計(フィルタ選択が反映されたスナップショット) |
| 2 | 7020ZAI | 在庫明細(F実残 / P岩崎伊東 / R,S,T ペットネーム・種別・販売区分は数式で保存) |
| 3 | 見込型番とペットネーム | 見込マスター(全型番から自動抽出) |
| 4 | 全型番とペットネーム | 全型番マスター(F列VLOOKUP数式) |
| 5 | NGリスト | マスター未登録型番 |
| 6 | マスター重複 | 全型番マスターの重複型番 |

## データの保存と削除

### 自動保存(localStorage)

集計を実行するとブラウザ内(localStorage)にDBの内容が自動保存されます。
次回HTMLを開いたときも、前回の集計結果がそのまま表示されます。

- 保存場所: ブラウザのローカルストレージ(Windows: `C:\Users\<ユーザー名>\AppData\Local\Microsoft\Edge\User Data\Default\Local Storage\` 等)
- 保存容量: 約5〜10MB(ブラウザによる)
- **注意**: 保存はブラウザ単位。EdgeとChromeでは別々に保存されます

### 「保存データを消去」ボタン

localStorage上の全データを削除して、初期状態に戻します。
実行前に確認ダイアログが表示されます。

### 「DBをバックアップ」ボタン

現在のDBを `.sqlite` ファイルとしてダウンロードします。
複数PCで共有したい場合や、履歴として残したい場合に使えます。

## トラブルシューティング

### 「ファイル名を選択」を押しても反応しない
- ブラウザで開いていない可能性があります。ファイルを右クリック → 「プログラムから開く」→ Microsoft Edge

### 「シートが見つかりません」エラー
- マスターExcelは「全型番とペットネーム」というシート名が必要です
- 在庫Excelは「7020ZAI」というシート名が必要です(見つからない場合は先頭シートを読みます)

### ダウンロードした結果Excelを開いてもペットネームや種別が空
- Excelを一度開いた際「保護されたビュー」の解除が必要な場合があります。上部の「編集を有効にする」をクリックしてください
- 数式が自動計算されないブラウザ環境で保存された可能性 → Excelで「F9」キー(全再計算)を押してください

### 動作が重い
- 大量データ(在庫10,000行以上)の場合、集計に10〜30秒かかることがあります
- ブラウザのタブを閉じずに待ってください

### データが消えた
- ブラウザの「閲覧履歴データを削除」でCookie/サイトデータを消去すると、localStorageも消えます
- 大切なデータは「DBをバックアップ」ボタンで .sqlite ファイルに保存してください

## セキュリティ

- 全てのデータ処理はブラウザ内部で完結します
- サーバーへの送信・外部通信は一切ありません(オフラインでも動作します)
- 会社の機密データを扱う場合でも、社外に情報が漏れることはありません
