SYSTEM OVERVIEW

オーダーステータス変更分抽出システム

受注データの「入庫日（納期）」が変わった行だけを、2つのExcelを突き合わせて自動抽出する業務ツールです。ブラウザだけで動き、データは外部に送信されません。

✔ インストール不要（HTMLを開くだけ） ✔ すべてブラウザ内で処理 ✔ Excel(.xlsx)で出力 ✔ 納期短縮分を別出力
1. 解決できること 2. 基本の仕組み 3. 抽出ルール 4. 出力されるExcel 5. 画面イメージ 6. 動作環境・注意点 7. 用語集

1このシステムで解決できること

毎日の受注データ更新で「どの製品の入庫日（納期）が動いたか」を、目視と手作業で探していませんか。

よくある困りごと

Before（手作業）

  • 変更前後の受注データをExcelで並べ、目で追って探す
  • 行数が多く、見落とし・転記ミスが起きやすい
  • 納期が「早まった（短縮）」ものと「遅れた」ものの区別が難しい
  • 抽出した結果を整形（見出し・フィルタ）するのに時間がかかる

After（このシステム）

  • 2つのExcelを読み込むだけで、変更行を自動抽出
  • キー（製品名＋受注ＮＯ）で正確に突合し、入庫日の差異だけを判定
  • 納期短縮分は自動で別ファイルに分離
  • 見出し装飾・固定・オートフィルタ付きのExcelをそのまま出力

2基本の仕組み

処理は「読み込み → 前処理 → 突合・抽出 → 出力」の4段階。すべてブラウザ内で完結します。

▲ 全体の処理フロー。AとBを前処理した後、キーで突合し、入庫日の変化だけを出力します。

① 読み込み

ファイルA（変更前）とファイルB（変更後）を選択、またはドラッグ＆ドロップ。シートも切替可能。

② 前処理（自動）

1行目を所定の16列ヘッダーに置換し、全セルの半角・全角スペースを削除。表記ゆれの影響を減らします。

③ 突合・抽出

製品名＋受注ＮＯをキーに1対1で照合し、入庫日が異なる行を抽出。B側が早い（短縮）行は別枠へ。

④ 出力

結果をExcel(.xlsx)で保存。見出しの青背景・太字・中央揃え、1行目の固定、オートフィルタが自動で付きます。変更が1件も無い場合は画面上に「オーダーステータス変更無し」と大きく表示します。

3抽出ルール（何を「変更」とみなすか）

判定ロジックは決め打ちです。列の位置ではなく「列名」で項目を特定します。

突合キーと比較する列

役割項目内容
キー①製品名（D列）同じ製品名どうしを対応付けます。
キー②受注ＮＯ（K列）受注番号まで一致する行を同一注文として突合。
比較入庫日（E列）この値が A と B で異なる行を「変更」と判定。
判定のポイント キー（製品名＋受注ＮＯ）が一致する行同士を、出現順に1対1で比較します。キーのいずれかが空欄の行は対象外です。

3つの判定結果

ケース条件行き先出力
変更あり（通常） 入庫日が異なり、変更後（B）が当初（A）以降（同じ or 遅い） 「抽出結果」 保存可
納期短縮 入庫日が異なり、変更後（B）が当初（A）より前（早い） 「納期短縮抽出結果」（別枠に分離） 保存可
変更なし 入庫日が同じ、または該当キーが無い／変更が1件も無い 出力なし（画面に大きなメッセージ） 保存不可

具体例で確認

製品名受注ＮＯA：当初入庫日B：変更後入庫日判定
モーターA10012026/11/202026/11/25通常（遅延）
ギアB10022026/10/302026/10/28納期短縮
センサーC10032026/12/012026/12/01変更なし

※ 日付は文字列・日付セル・数値のいずれでも比較できます（年/月/日の形式を自動解釈）。

4出力されるExcel

出力は「抽出結果」と「納期短縮抽出結果」の2種類。どちらも見出し装飾・固定・フィルタ付きです。

「抽出結果」の列構成

#列名内容
1ＮＯ連番
2製品コードAファイルの値
3製品名Aファイルの値
4当初入庫予定日A（変更前）の入庫日
5変更後入庫予定日B（変更後）の入庫日。見出しは赤で強調
6生産数Aファイルの値
7登録日Aファイルの値
8希望日Aファイルの値
9営ＣAファイルの値
10向先名Aファイルの値
11受注ＮＯAファイルの値

※ 「納期短縮抽出結果」も同じ列構成で、納期が早まった行だけを収録します。

自動で付く書式

  • 1行目：青背景・白文字・太字・中央揃え
  • 対象列「変更後入庫予定日」の見出しは赤背景
  • 1行目を固定（スクロールしても見出しが残る）
  • オートフィルタ付き

ファイル名

通常
伊東電機製品オーダーステータス変更情報_yymmddhhmm.xlsx

短縮
伊東電機製品オーダーステータス変更情報【納期短縮】_yymmddhhmm.xlsx

※ 末尾は保存日時（年下2桁＋月日＋時分）。上書き事故を防ぎます。

前処理後のデータも保存できる

「ファイルA（前処理後）をダウンロード」「ファイルB（前処理後）をダウンロード」から、見出し置換・空白削除を済ませた状態のExcelも保存できます。突合前のデータ確認や、他システムへの受け渡しに使えます。

6動作環境・注意点

動作環境

対応ブラウザMicrosoft Edge / Google Chrome 推奨（最新版）
入力ファイル.xlsx / .xls / .csv
出力.xlsx（Excel）
インストール不要（HTMLを開くだけ）
通信初回のみライブラリ取得のためネット接続が必要

安心して使うために

  • 受注データはブラウザ内だけで処理され、サーバーへは送信されません。
  • ページを再読み込みすると読み込んだ内容は消えます（保存されません）。
  • Excel出力はブラウザのダウンロード機能を使います。
  • 処理はPCの性能とデータ量に依存します。件数が多いと数秒かかることがあります。
ネット接続について このツールは表計算処理ライブラリ（SheetJS・fflate）をCDNから読み込みます。初回表示時にインターネット接続が必要です。オフライン環境で使う場合は、事前にライブラリをローカル保存する対応が必要です。

7用語集

用語説明

キー行を対応付けるための項目。本システムは「製品名＋受注ＮＯ」。
入庫日製品が入庫する予定日（納期）。本システムで変化を判定する対象。
納期短縮変更後の入庫日が当初より早くなること。
前処理見出しの置換や空白削除など、突合前の下ごしらえ。
