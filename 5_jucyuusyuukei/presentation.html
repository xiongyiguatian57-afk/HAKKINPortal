System Overview

工程計画 受注データ集計システム

受注Excelと型番マスタを取り込み、自由な軸でピボット集計 → Excel出力。クラウド版・スタンドアロン版の2本立てで提供。

v1.0 本開発リリース 2026年10月15日 現在 対象: 工程計画 業務 データ件数: 受注 約3,700行 / マスタ 約1,970件

1システムの主旨・解決する課題

現場で散在する受注Excelと型番マスタをブラウザ上で集約し、「誰が・いつ・どの製品を・何個生産するか」を任意の軸で自由に集計できる業務ツールです。

これまでの課題

Excel手作業でピボット作成。担当者・ペットネーム・月別の集計を都度組み直す必要があり、属人的で時間がかかる。

本システムの解決策

取込→集計→出力をブラウザで完結。マスタと受注を自動結合し、14項目の多軸フィルタ+複数指標の同時集計を数秒で実行。

導入効果

月次レポート作成の工数を大幅短縮。Excel書式も自動整形、担当者間での集計結果ブレを解消。

22つの提供形態 (併用可能)

利用シーンに応じてクラウド版とスタンドアロン版のどちらも維持しています。両版は同じ操作性・同じ集計結果になるよう仕様統一されています。

観点クラウド版スタンドアロン版
用途 常時利用・共有 複数人で同じデータを共有 オフライン・持出 個人PCでの一時利用・外出先
動作環境 Webブラウザ (Genspark ワークスペース) Chrome / Edge で単一HTMLファイルを開くだけ
データ保存 サーバー側 PostgreSQL ブラウザ内 IndexedDB (SQLite WASM)
インストール 不要 (URLでアクセス) 不要 (HTMLファイルをダブルクリック)
ネットワーク 常時必要 初回のみ必要 (CDNキャッシュ後はオフライン可)
データ共有 自動 (同じワークスペースで共有) 手動 (SQLiteファイルのエクスポート/インポート)
想定ユーザー 複数部門・常時利用者 個別担当・持出用途
両方を同時に維持する運用: クラウド版は本番共有用、スタンドアロン版は個別検証・持出用として役割分担。データは分離されているため、必要に応じて同じExcelを両方に取り込めば結果を照合できます。

3システム構成

クラウド版 アーキテクチャ

利用者 (Webブラウザ) ──▶ データ取込ビュー + ピボット集計ビュー
    │
    ▼ (SQL実行)
Genspark Workspace (PostgreSQL)
    ├─ orders (受注データ 約3,700行)
    ├─ product_master (型番マスタ 約1,970件)
    └─ import_log (取込履歴)

スタンドアロン版 アーキテクチャ

利用者 (Chrome/Edge) ──▶ 単一HTML (約87KB)
    │
    ├─ SQL.js (WASM SQLite)
    ├─ xlsx-js-style (Excel入出力)
    ▼ (400msデバウンス自動保存)
ブラウザ内 IndexedDB ──▶ .sqlite ファイル (エクスポート)

4業務フロー

日常業務での操作は4ステップで完結します。マスタ取込は初回・マスタ更新時のみ、受注取込は定期的 (日次 / 週次) に行います。

データの流れ (詳細)

[受注Excel] ──取込──▶ orders テーブル
    │
[マスタExcel] ──取込──▶ product_master テーブル
    │
    ▼ 自動結合 (製品コードで一致)
    ├─ マッチ製品 → ペットネーム・種別・販売区分 付与
    └─ 未マッチ製品 → デフォルト値付与、UIで一覧表示
    │
    ▼ ピボット集計 (フィルタ適用 → 行×列×値)
    ▼
[Excel出力] (ピボットシート + マスタ未マッチシート)

5主な機能

5-1. データ取込

受注データExcel

  • スナップショット型 (取込ごとに全置換)
  • ドラッグ&ドロップ対応
  • 日付・数値・文字列の型自動判定
  • 取込履歴に件数・日時を自動記録

型番マスタExcel

  • 製品コード → ペットネーム・種別・販売区分 のマッピング
  • マスタ更新後に受注データを自動再結合
  • 未マッチ製品はデフォルト値で集計に含める

5-2. ピボット集計 (14項目フィルタ + 複数指標)

カテゴリ対象項目操作方式
カテゴリ系 (8項目) 営C / 種別 / 販売区分 / 向先名 / 受注NO / 担当 / ペットネーム / 製品名 検索付きチェックボックス + 全選択/クリア
月範囲開始月〜終了月ドロップダウン (YYYY年M月)
数値範囲 (5項目) 生産数 / 金額 / 関連購入金額 / 完了数量 / 未完了残数 最小〜最大入力
マッチ状態全て / マスタとマッチ済 / 未マッチのみラジオ選択

5-3. 複数値集計 (値 × 集計方式)

集計対象 (複数選択可)集計方式 (複数選択可)組合せ例
生産数 / 未完了残数 / 完了数量 / 金額 / 関連購入金額 合計 / 件数 / 平均 / 最大 / 最小 [金額, 生産数] × [合計, 平均] = 4指標を同時表示

5-4. Excel出力の書式

見出し

薄青 + 太字 (2段ヘッダ対応)

データ罫線

全セルに thin border

総計行列

薄グレー + 太字、総計×総計は濃紺+白

数値書式

3桁カンマ、平均は小数2桁
