## 1. 導入方法

### クラウド版
Gensparkワークスペース「工程計画 受注データ集計」を開き、サイドバーから以下のいずれかを選択:
- **「データ取込 (受注データ、マスタ)」** — Excelを取り込む
- **「工程計画 ピボット集計」** — 集計・出力する

### スタンドアロン版
1. `受注データ集計ツール_v1.0.html` をChrome または Edge で開く(ダブルクリック)
2. 初回起動時に SQL.js(WebAssembly SQLite)を CDN からロード(数秒)
3. ヘッダ右上に「保存済み」表示が出れば準備完了

**初回だけインターネット接続が必要** (CDNキャッシュ後はオフライン動作可)

## 2. 基本操作フロー

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ ①マスタ取込  │ →  │ ②受注データ取込│ →  │ ③ピボット集計 │ →  │ ④Excel出力   │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

**必ずマスタから先に取り込むこと。** 受注データを先に取り込むと、その時点でマスタ未登録の型番はすべて「未マッチ」扱いになります(後からマスタを追加して「再結合」で復旧可能)。

## 3. データ取込

### 3-1. 型番マスタの取込

1. **データ取込タブ** の「型番マスタExcel」欄で:
   - ファイルをドラッグ&ドロップ、または「ファイルを選択」でExcelを指定
2. 「マスタを取込む」ボタンをクリック
3. プログレスバーで進捗を確認 → 完了

**期待する列** (順不同、列名で判定):
- No / 型式(製品コード) / 目印 / ペットネーム / 種別 / 販売区分

### 3-2. 受注データの取込

1. **データ取込タブ** の「受注データExcel」欄で:
   - Excelファイルをドラッグ&ドロップ、または選択
2. 「受注データを取込む」ボタンをクリック
3. 既存の受注データは**全置換**されます(スナップショット型)

**期待する列**:
- No / 担当 / 製品コード / 製品名 / 入庫日 / 生産数 / 登録日 / 希望日
- 営C / 向先名 / 受注NO / 完了数量 / 製造部門コード / 代表入庫場所
- 最新販売原価 / 関連購入単価 / 未完了残数 / 月 / 金額 / 関連購入単価金額

### 3-3. 取込後の状態確認

「データ取込」タブ下部の**取込履歴**とKPIカードで以下を確認:
- 受注データ行数(例: 3,730行)
- マスタ登録数(例: 1,978件)
- マスタ未マッチ数(0であれば全て正常結合)

## 4. ピボット集計

### 4-1. 画面構成

```
┌─ KPIカード(受注行数・マスタ数・未マッチ数・合計生産数・合計金額) ─┐
├─ フィルタ条件(14項目) ────────────────────────────┤
├─ 集計設定(行/列/値/集計方法) ────────────────────┤
├─ [集計結果 | マスタ未マッチ] タブ ─────────────────┤
└─ ピボットテーブル ────────────────────────────────┘
```

### 4-2. フィルタの使い方

#### カテゴリ系フィルタ(8項目)
- 各フィルタ枠の「検索…」欄に文字入力で候補を絞り込み
- チェックボックスで複数選択(何も選ばなければ**全て**)
- 「全選択」「クリア」ボタンで一括操作
- 選択件数はフィルタ枠下部に表示

#### 月範囲フィルタ
- 「開始月〜終了月」をドロップダウンで指定
- 片方だけ指定すると片開きの範囲になる
- 空欄なら全期間

#### 数値範囲フィルタ(5項目)
- 「最小」「最大」に数値を入力
- 片方だけ入力してもOK

#### マッチ状態フィルタ
- 「全て」「マスタとマッチ済のみ」「未マッチのみ」から選択

「条件をリセット」ボタンで全フィルタをクリアできます。

### 4-3. 集計設定

| 項目 | 説明 |
|---|---|
| **行(縦軸)** | ピボットの行に配置する項目 |
| **列(横軸)** | ピボットの列に配置する項目 (「(なし)」を選ぶと集計のみ) |
| **集計対象** | 値フィールド(**複数選択可**): 生産数 / 未完了残数 / 完了数量 / 金額 / 関連購入金額 |
| **集計方法** | チップUIで**複数選択可**: 合計 / 件数 / 平均 / 最大 / 最小 |

「集計を実行」でテーブルに反映されます。

### 4-4. 複数値集計の例

- 値=[金額, 生産数] × 集計=[合計, 平均] を選ぶと **4指標**(金額の合計・金額の平均・生産数の合計・生産数の平均)が同時表示
- ヘッダは自動で2段になり、上段=列カテゴリ、下段=指標名 になる

### 4-5. 月連続化

行または列に「月」を選ぶと、データに含まれる最小月〜最大月を1ヶ月刻みで自動生成します。欠損月のセルは 0 で表示されます。

例: データが 2026年9月と 2027年1月しかなくても、10月・11月・12月も列として現れ、値は0になります。

## 5. Excel出力

「Excel出力」ボタンで `工程計画ピボット_YYYYMMDD_HHMM.xlsx` を生成します。

**含まれるシート**:
1. **ピボット** — 集計条件のメタ情報 + ピボット結果
2. **マスタ未マッチ** — 未マッチ製品が存在する場合のみ添付

**書式**:
- 見出し行: 太字 + 薄青塗り
- データ行: 罫線付き
- 総計列: 太字 + 薄グレー塗り
- 総計行×総計列: 濃紺 + 白文字
- 数値: 3桁カンマ(平均は小数2桁)
- 月ヘッダ: Excel Date型 (`yyyy"年"m"月"`)
- 列幅・行高自動調整、ヘッダ行フリーズ

**注意**: 単一値集計時は1段ヘッダ、複数値集計時は2段ヘッダ(colspanマージあり)。

## 6. 未マッチ製品の対処

### 6-1. 未マッチとは
受注データの製品コードが型番マスタに登録されていない状態です。ピボット集計時は
- ペットネーム = 「その他」
- 種別 = 「それ以外」
- 販売区分 = 「#N/A」

として扱われます。

### 6-2. 確認方法
1. 「マスタ未マッチ」タブを開く
2. 該当製品コード・製品名を確認
3. 上部KPIカードに「マスタ未マッチ」件数が黄色で表示される

### 6-3. 復旧方法
1. マスタExcelに該当型式を追加
2. マスタを再度取込む
3. 自動で「再結合」が実行され未マッチ製品もマスタ情報が反映される

### 6-4. CSV出力
「マスタ未マッチ」タブ内の「CSVダウンロード」ボタンで未マッチ一覧のみExcel(.xlsx)出力可能。マスタ整備担当への連絡に使えます。

## 7. スタンドアロン版特有の機能

### 7-1. 自動保存
- 受注データ・マスタ・取込履歴はブラウザの IndexedDB に自動保存(400msデバウンス)
- 次回起動時に自動復元
- ヘッダ右上に保存ステータス表示(保存中 / 保存済み)

### 7-2. DB管理

「DB管理」セクションで以下が可能:
- **SQLiteファイルのエクスポート**: `受注データ集計DB_YYYYMMDD.sqlite` として保存 → 別PCへ移行や共有に使う
- **SQLiteファイルのインポート**: エクスポートしたファイルを読み込んで復元
- **全データリセット**: 受注・マスタ・履歴を全削除
- **ストレージ使用量**: 現在のIndexedDB使用量を表示

### 7-3. データの共有
複数PCで使う場合の推奨手順:
1. マスタ担当のPCでマスタをエクスポート → SQLiteファイル配布
2. 各PCでインポート → マスタ共有完了
3. 各自で受注データを取込

**注意**: 同時編集や自動同期はありません。共有フォルダに置いてSQLiteファイルを共有する運用が最もシンプルです。

## 8. よくある質問(FAQ)

**Q1. クラウド版とスタンドアロン版のデータは同期されますか?**
→ 同期されません。データは完全に分離されています。

**Q2. マスタを取込むと受注データも消えますか?**
→ 消えません。マスタと受注は独立に取り込まれ、自動で再結合されます。

**Q3. 大量データ(10万行以上)を扱えますか?**
→ v1.0は数千〜数万行想定です。10万行以上はパフォーマンスが低下します。要望があれば最適化検討します。

**Q4. Excel出力の書式が崩れます**
→ Excel 2010以降推奨。Excel 2007以前や LibreOffice ではセル書式(色・罫線)の互換性に注意。

**Q5. 「月」列が空欄の受注データはどう扱われますか?**
→ 「(空欄)」として1グループにまとめられます。

**Q6. スタンドアロン版でネットは必須ですか?**
→ 初回のみ必要(CDNから SQL.js と xlsx-js-style をロード)。以降はブラウザキャッシュで動作します。

**Q7. IndexedDB のデータはいつまで残りますか?**
→ ブラウザのデータを消去しない限り永続保存。念のため定期的にSQLiteファイルにエクスポートしてバックアップを取ることを推奨。

## 9. トラブルシューティング

### スタンドアロン版が起動しない
- Chrome / Edge の最新版を使用してください(Safari / Firefox は未サポート)
- 初回起動時はインターネット接続が必要です
- ブラウザのコンソール(F12)にエラーがないか確認

### Excel取込でエラー
- ヘッダ行(1行目)に想定列が含まれているか確認
- Excel内のマクロやフォーム挿入は取込前に削除してください
- 「.xlsx」形式であること(.xls / .csv は未対応)

### 集計結果が想定と違う
- フィルタの選択状態を確認("何も選択していない = 全て")
- 「マッチ状態」フィルタが未マッチのみになっていないか
- 数値範囲フィルタの最小/最大が意図した値か
- 「条件をリセット」で全クリアしてから再確認

### スタンドアロン版のデータが消えた
- ブラウザの「閲覧履歴を消去」でIndexedDBも削除された可能性
- 「シークレットモード」で開くと毎回リセットされる
- 対策: SQLiteファイルを定期的にエクスポートしてバックアップ

### Excel出力で書式が反映されない
- スタンドアロン版・クラウド版とも `xlsx-js-style` を使用(セル書式対応版)
- Excel 2010以降で開くこと
- ネット切断中はCDNから xlsx-js-style がロードできず出力できない場合あり
