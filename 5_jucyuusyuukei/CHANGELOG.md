# 変更履歴 (CHANGELOG)

## v1.0 (2026-09-17) — 本開発リリース

### 新機能
- **フィルタ強化**:
  - カテゴリ系フィルタ8項目に検索ボックス + 「全選択」「クリア」ボタン
  - 新規: 月範囲フィルタ(開始月〜終了月ドロップダウン)
  - 新規: 数値範囲フィルタ5項目(生産数 / 金額 / 関連購入金額 / 完了数量 / 未完了残数)
  - 新規: マッチ状態フィルタ(全て / マッチ済 / 未マッチのみ)
- **複数値集計**:
  - 値フィールドを複数選択可能(チェックボックスUI)
  - 集計方式を複数選択可能(チップUI)
  - 例: 値=[金額, 生産数] × 集計=[合計, 平均] → 4指標を同時表示
  - 複数値選択時は自動で2段ヘッダに切替
- **Excel出力書式強化**:
  - 罫線(全データセル)
  - 見出し行の背景色 + 太字
  - 総計行/列の背景色 + 太字
  - 総計×総計セルの強調表示
  - 数値書式(3桁カンマ、平均は小数2桁)
  - ヘッダ行のフリーズ枠
  - 複数値集計時のcolspanマージ

### 変更
- スタンドアロン版・クラウド版とも `xlsx-js-style@1.2.0` に切替(セル書式対応)
- named query `pivot_data` に `matched` 列を追加(マッチ状態フィルタ対応)
- スタンドアロン版の内部SQLite pivot_data クエリも同様に更新

### ドキュメント
- 利用マニュアル(MANUAL.md)を新規作成
- README.md を整備

## v0.1 (2026-09-17) — スタンドアロン版PoC

### 新機能
- スタンドアロン版(単一HTML)を新規作成
- SQL.js (WebAssembly SQLite) + xlsx (SheetJS Community) を CDN 経由でロード
- IndexedDB 自動保存(400msデバウンス、次回起動時に自動復元)
- クラウド版と同等の機能セット:
  - 受注データExcel取込(スナップショット型)
  - 型番マスタExcel取込
  - マスタ変更時の自動再結合
  - ピボット集計(単一値・単一集計)
  - マスタ未マッチタブ
  - Excel出力
- DB管理機能:
  - SQLiteファイルのエクスポート/インポート
  - 全データリセット
  - ストレージ使用量表示

## 事前作業(v0.1 以前・クラウド版のみ)

### クラウド版UI改善
- タイトルを「工程計画 ピボット集計」に変更
- 右上に「ピボット集計を開く」「データ取込を開く」ボタン追加
- 「データ取込を開く」クリック時にサイドバー切替を促す案内オーバーレイ実装
  (iframe cross-origin制約により自動遷移不可のため)

### 月表記統一
- 受注データの `月` 列を `YYYY年M月` 形式(西暦付き)に統一
- DB既存データを一括UPDATE

### 月連続化ヘルパ
- `buildMonthRange()` / `parseMonthLabel()` / `smartSort()` を実装
- 行/列に月を指定した際、min〜max を1ヶ月刻みで連続生成
- 欠損月のセルは 0 で埋める

### Excel月ヘッダの日付化
- Excel出力時、月ヘッダを Date型 (`yyyy"年"m"月"` 書式) で出力
- 単なる文字列ではなく日付ソート・書式変更可能
