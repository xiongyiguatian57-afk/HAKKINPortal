# 工程計画 受注データ集計ツール v1.0

受注データ(Excel)と型番マスタ(Excel)を取り込み、任意の軸で自由にピボット集計してExcel出力するツールです。

## 提供形態

| 版 | 用途 | 動作環境 | データ保存先 |
|---|---|---|---|
| **クラウド版** | 常時利用・共有 | Webブラウザ(Genspark ワークスペース) | サーバー(PostgreSQL) |
| **スタンドアロン版** | オフライン利用・持出 | Chrome / Edge(HTMLファイルを開くだけ) | ブラウザ内 IndexedDB |

両版は**同じ操作性・同じ集計結果**になるように仕様統一されています。データは分離されているため併用可能です。

## 主な機能

### データ取込
- 受注データExcel(スナップショット型:取込ごとに全置換)
- 型番マスタExcel(製品コード → ペットネーム/種別/販売区分)
- 未マッチ製品はマスタ登録後の「再結合」機能で自動反映
- 取込履歴の一覧表示

### ピボット集計
- **フィルタ** (14項目):
  - カテゴリ系(8項目): 営C / 種別 / 販売区分 / 向先名 / 受注NO / 担当 / ペットネーム / 製品名 — 検索付きマルチセレクト
  - 月範囲: 開始月〜終了月をドロップダウンで指定
  - 数値範囲(5項目): 生産数 / 金額 / 関連購入金額 / 完了数量 / 未完了残数 — 最小〜最大入力
  - マッチ状態: 全て / マスタとマッチ済のみ / 未マッチのみ
- **複数値集計**: 値(5種) × 集計方式(合計/件数/平均/最大/最小)を複数選択可能。階層ヘッダで同時表示
- **月連続化**: `YYYY年M月` を行/列に選ぶと最小〜最大月を1ヶ月刻みで自動連続化(欠損は0埋め)
- **未マッチ一覧**: マスタ未登録の型番を別タブで確認・CSV出力

### Excel出力
- ピボット結果 + マスタ未マッチシート
- 罫線・見出し色・小計太字・数値書式(3桁カンマ)・列幅自動調整・フリーズ枠付き
- 月ヘッダは Excel Date型 (`yyyy"年"m"月"`) で出力
