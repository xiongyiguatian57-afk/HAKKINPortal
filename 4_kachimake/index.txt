========================================================
白金ブランド生産計画 勝ち負け表 — 単独動作版
========================================================

【使い方】
1. 「勝ち負け表.html」をダブルクリック
   → 既定のブラウザ (Edge または Chrome) で開きます

2. 3つのタブがあります：
   ・「データアップロード」… 需要/供給/在庫の Excel ファイルを取り込み
   ・「勝ち負け表」……… 集計結果の表示と Excel 出力
   ・「バックアップ」……… JSON でのデータ書き出し/読み込み

3. データはこのブラウザ (Edge または Chrome) のローカル領域に自動保存されます
   → 次回開いたときも前回のデータがそのまま残っています


【動作環境】
・Windows 10 / 11
・Microsoft Edge または Google Chrome（最新版推奨）
・初回起動時のみインターネット接続が必要（ライブラリ取得のため）
　→ 2回目以降はオフラインでも動作します


【バックアップの推奨】
ブラウザのキャッシュを全削除するとデータも消えます。
月に1回程度、「バックアップ」タブから JSON を書き出して
保存しておくことを推奨します。


【他のPCへのデータ移行】
1. 元のPCで「バックアップ」タブ → 「全データをJSONに書き出し」
2. 生成された JSON ファイルを新しいPCへコピー
3. 新しいPCで「勝ち負け表.html」を開き、「バックアップ」タブ →
   「JSONから読み込み」でその JSON を選択


【困ったとき】
・データが表示されない
  → 「データアップロード」タブから需要/供給/在庫ファイルを
    再度取り込んでください
・「file:// では動作しません」等のエラー
  → ブラウザを Edge または Chrome に切り替えてください
    （Firefox は file:// で IndexedDB が無効化される場合あり）
